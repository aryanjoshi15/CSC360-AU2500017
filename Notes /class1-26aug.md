1.Application fields: astronomy, biomedical fields

2.Images are not only photographic, can be sonar images, xray images, thermal images. Tools used in cs are useful in all kinds of images.

3.Vector graphics: consists of mathematical code, does operation at runtime, so the image stays at full clarity on different sizes of display (no pixelation when scaled)

4.Videos are basically sequentially arranged images (frames played in order = motion)

5.Functions to do with graphics:

6.Translation - moving an object from one position to another (shifting along x/y) without changing size

7.Scaling - resizing an object bigger/smaller

8.Rotation - turning an object around a point by some angle.
